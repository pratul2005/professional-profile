# Academic Projects

## 1. SMS Spam Detection
- **Technologies:** Python, scikit-learn, TF-IDF, Multinomial Naive Bayes
- **Description:** A machine learning classifier trained to distinguish spam and legitimate SMS messages using the UCI SMS Spam Collection dataset.
- **Evaluation:** 96.77% accuracy on 1,115 held-out test messages in the recorded run.
- **Repository:** https://github.com/pratul2005/sms-spam-detection
